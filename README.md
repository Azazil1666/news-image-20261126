An entry for the [make.fun](https://make.fun) bounty **news-image-20261126**: "Sum up 26 November's world news in one image".

A dense 1024×1024 newspaper front page drawn entirely in code: 35 stories, all dated Thursday 26 November 2026, with a masthead, UTC timeline, world map with 12 numbered pins, region bars, source attribution, confidence tags, a Day in Numbers strip, and a DATE CHECK footer.

Built with Node 22, stdlib only, no network. Run `node main.ts` to generate `entry.png` — deterministic, byte-identical on every run.
